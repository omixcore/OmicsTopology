# PLOS Computational Biology reference audit

## Scope and results

- Audited 42 numbered references against Crossref metadata and publisher, PubMed/NCBI, arXiv, or Journal of Machine Learning Research records as appropriate.
- All 42 references are cited in the body; no uncited bibliography entries or missing reference numbers were found.
- First appearance order is sequential from [1] through [42], consistent with PLOS citation-sequence ordering.
- 39 references carry DOI identifiers; DOI/title matches were confirmed for the DOI-bearing records. Reference 17 now cites the published journal version rather than the arXiv preprint; its Crossref DOI metadata confirms title, authors, year, volume, issue, and pages.
- References 18, 35, and 41 have no DOI located; their authoritative publisher/journal pages are retained as online access points where appropriate.
- Reference 17 was updated to the published journal version (DOI 10.18255/1818-1015-2013-6-111-120) instead of the arXiv preprint. Reference 26 required an author-list cross-check because Crossref returned incomplete author metadata; the three-author list is supported by NCBI records.
- Reference 33 was corrected to the PLOS rule of listing the first six authors followed by “et al.” Journal titles have been changed to standard abbreviations, titles normalized to sentence case, and DOI strings changed to the PLOS “doi: …” form.

## PLOS formatting changes applied

- In-text references remain in square brackets and first-citation order is sequential.
- Reference list uses Vancouver/ICMJE structure, standard journal abbreviations, first six authors followed by “et al.” where needed, and `doi:` labels rather than DOI URLs.
- Added a 150–200-word Author Summary after the abstract.
- Added software name to the title; retained an original-research format rather than the separate Software Submission format.
- Set 12-point Times New Roman, double spacing, one-inch margins, page numbers, and continuous line-number settings.
- Moved main figure captions to follow the paragraph where each figure is first cited; changed labels to “Fig 1” etc. Added supporting-information captions after the reference list using PLOS `S1 Fig` / `S1 Table` labels.
- Removed the funding section from the manuscript file because PLOS directs authors to enter funding only in the online Financial Disclosure form. A separate submission-metadata file retains the supplied grants and flags remaining author confirmations.
- Changed “Conflict of Interest” to “Competing interests.”

## Remaining author/submission confirmations

- Confirm grant recipient initials and official funder URLs in the submission form. PLOS asks whether funders had any role in study design, data collection/analysis, publication decision, or manuscript preparation; this has not been assumed.
- Obtain a fixed archival DOI for the exact code/data snapshot if possible; PLOS strongly recommends a permanent repository identifier.
- Confirm all authors have reviewed the final contribution statement and corresponding-author email.
